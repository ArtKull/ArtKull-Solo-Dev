# ArtKull — дизайн-гайд

Дизайн-система одностраничного сайта ArtKull (веб-разработка на заказ).
Документ описывает визуальный язык, токены и компоненты. Источник требований —
`structure.md` и `visual system.md`, зафиксированные решения — в `docs/spec.md`.

## 1. Философия

**«Дашборд, а не брошюра».** Сайт выглядит как современный рабочий инструмент
(Linear, Vercel, админ-панели), а не как классический маркетинговый лендинг.
Метрики, статусы, бейджи и моноширинные числа создают ощущение работающего
продукта и профессиональной инженерной культуры.

Четыре принципа:

1. **Размер карточки = её приоритет.** Ключевое сообщение занимает больше места.
2. **Интерфейсные детали как декор.** Статус-точки, прогресс-бары, лейблы —
   не украшения, а язык, на котором говорит бренд.
3. **Сдержанность.** Один акцент, один набор иконок, минимум анимаций.
4. **Честность.** Никаких «бумажных» агентских обещаний — цифры и конкретика.

## 2. Логотип и бренд

- **Знак:** сетка 3×3 из скруглённых квадратов (bento-паттерн). Отражает сеточную
  природу вёрстки и совпадает с эстетикой сайта.
- **Текстовая часть:** «Art**Kull**» — `Art` в цвете основного текста, `Kull`
  в акцентном цвете. Теглайн `web development` — моноширинный, вторичный цвет,
  lowercase.
- **Форматы:** `assets/logo.svg` (горизонтальный, знак + текст) и
  `assets/favicon.svg` (только знак 3×3).
- **Охранное поле:** не менее 8px вокруг знака.
- **Минимальный размер:** высота знака — 24px.
- Нельзя: менять цвета квадратов, растягивать, добавлять тень/обводку,
  перекрашивать акцент логотипа в другой цвет.

### Правила

- Акцент — рабочий цвет, не заливка всей страницы. Крупная заливка только в
  секции CTA.
- Статус-цвета: `--success` для «включено/готово», `--text-muted` для «не входит».
- Контраст текста к фону — не ниже 4.5:1 (AA). Для крупного текста ≥ 3:1.
- **Три акцентных токена по назначению.** `--accent` (`#3B82F6`/`#60A5FA`) —
  бренд-цвет для границ, иконок, прогресса и крупных элементов. `--accent-solid`
  (`#2563EB`) — только для заливок под белым текстом (primary-кнопка, бейдж
  «Популярный», фон CTA): белый текст на `#2563EB` даёт 5.1:1. `--accent-text`
  (`#2563EB` в светлой, `#60A5FA` в тёмной) — для мелкого акцентного текста и
  ссылок. Прямое использование `--accent` под белым текстом или мелким текстом
  на светлом фоне — запрещено (контраст < 4.5:1).

## 4. Типографика

- **Заголовки и текст:** Inter (400/500/600/700). Google Fonts, `display=swap`.
- **Технические акценты:** JetBrains Mono (500) — цены, числа метрик,
  микро-лейблы. Это «дев-вайб» бренда.
- Рекомендуется `font-feature-settings: "ss01"` для Inter.

## 5. Пространство, сетка, раскладка

- **Bento-grid:** 12 колонок, gap 16px, контейнер `max-width: 1200px`,
  padding 24px по бокам.
- **Брейкпоинты:** desktop ≥ 1024px (12 колонок), tablet 640–1023px (2 колонки),
  mobile < 640px (1 колонка).
- **Шкала отступов:** 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64.
- **Внутренние паддинги карточек:** 24px на десктопе, 20px на мобильном.

## 7. Компоненты

Все компоненты используют токены; состояния описаны явно.

**card** — фон `--surface`, радиус 16, паддинг 24, тень. Варианты:
`card--accent` (border в цвет акцента + усиленная тень, для популярного тарифа),
`card--flat` (без тени, только border).

**badge** — пилюля, `radius-el`, 12px uppercase, `letter-spacing .08em`.
Варианты: `badge--neutral` (серый фон, muted), `badge--accent` (заливка акцентом,
белый текст), `badge--outline`.

**btn** — высота 44, паддинг 0 20, `radius-el`, 14px/600.
- `btn--primary` — фон акцент, текст белый, hover `--accent-hover`.
- `btn--outline` — прозрачный фон, border `--border`, hover подложка `--surface-2`
  и border акцента.
- `btn--ghost` — без фона и границы, текст акцент.
Состояния: hover, active (`translateY(1px)`), focus-visible (кольцо 2px
акцент с offset 2).

**check** — строка чек-листа, 14px. `check--on`: глиф ✓ в круге `--success`,
текст `--text`. `check--off`: глиф ○ серый, текст `--text-muted`.

**pill** — тег навыка, `radius-pill`, фон `--surface-2`, border `--border`,
12px/500, паддинг 4 12. Hover — border акцента.

**metric** — блок метрики: число (JetBrains Mono 32/500) + лейбл
(12px uppercase muted). Вертикальная раскладка.

**progress** — полоса 4px, `radius-pill`, фон `--surface-2`, заливка `--accent`,
анимация ширины при появлении.

**field** — input высотой 44, `radius-el`, фон `--surface-2`, border `--border`,
паддинг 0 14. Placeholder — muted. Focus — border акцента + кольцо.

**status-dot** — точка 8px: `--success` (онлайн) или `--text-muted` (выкл.),
с лёгким glow у зелёной (box-shadow в цвет).

**icon** — инлайн-SVG, `stroke-width: 1.5`, `fill: none`, `currentColor`.
Стиль линейный. Производные размеры: 16 / 20 / 24px.

**theme-toggle** — круглая кнопка 40px в правом верхнем углу hero,
иконка солнца/луны, `aria-pressed`. Focus-visible как у btn.

**section-header** — вертикальный стек: микро-лейбл (JetBrains Mono uppercase
muted) + H2.

**timeline-node** — кружок 36px с номером (JetBrains Mono, акцентный фон при
активном/пройденном), соединён линией 1px `--border`.

## 8. Движение и анимация

- **Появление секций:** fade-in-up (opacity 0→1, `translateY(16px→0)`), 400ms,
  `cubic-bezier(.2,.7,.3,1)` через IntersectionObserver. Триггер — один раз.
- **Hover карточек:** `translateY(-4px)` + усиление тени, 200ms ease.
- **Hero-дашборд:** числа появляются стаггером слева-вправо, 80ms между метриками.
- **Прогресс-бары этапов:** ширина 0 → значение, 600ms.
- **Smooth-scroll** по якорям, `scroll-behavior: smooth`.
- **`prefers-reduced-motion: reduce`:** все трансформации и переходы отключены,
  контент виден сразу.

Правило: не более одного типа появления на элемент, без параллакса и без
анимации на скролл-скрутку.

## 9. Иконки

Единый линейный набор в стиле Lucide (рисуются инлайн-SVG): молния, тег/рубль,
пользователь, телефон, письмо, мессенджеры, соцсети, геолокация, солнце/луна,
галочка, внешняя ссылка. Не смешивать с другими наборами.

## 10. Доступность

- Семантические лендмарки: `header`, `main`, `section`, `footer`, `nav`.
- `focus-visible` на всех интерактивных элементах, порядок фокуса логичный.
- Иконки-ссылки имеют `aria-label`; декоративные — `aria-hidden="true"`.
- Toggle темы: `aria-pressed` и доступное имя.
- Контраст AA, текст ≥ 4.5:1.
- Ссылки-якоря работают с клавиатуры, без перехвата Tab.

## 11. Справочник токенов

Полный список `:root` (светлая) и `[data-theme="dark"]` (тёмная) — в
`css/tokens.css`; таблицы выше — источник истины. Токены: цвета (`--bg`,
`--surface`, `--surface-2`, `--text`, `--text-muted`, `--accent`,
`--accent-hover`, `--accent-soft`, `--success`, `--border`), тени
(`--shadow`, `--shadow-lifted`), радиусы, шкала отступов (`--space-*`),
шрифтовые стеки (`--font-sans`, `--font-mono`).
