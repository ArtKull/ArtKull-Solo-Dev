# ArtKull — спецификация сайта

Одностраничный статический сайт-лендинг. Визуальный язык — `docs/design-guide.md`.
Исходные требования — `structure.md`, `visual system.md`.

## 1. Обзор

Сайт персонального веб-разработчика (бренд **ArtKull**) для привлечения заказов
на разработку сайтов у малого и среднего бизнеса. Ключевое сообщение: «один
человек — полная ответственность, быстрее и дешевле агентства».

**Целевая аудитория:** владельцы и маркетологи малого/среднего бизнеса,
предприниматели, которым нужен сайт без агентской наценки.

**Целевое действие:** оставить заявку (форма-заглушка) или написать в мессенджер
по ссылке из блока контактов.

**Язык:** русский.

## 2. Технические решения

| Область            | Решение                                                        |
|--------------------|----------------------------------------------------------------|
| Стек               | Чистый HTML5 + CSS3 + vanilla JS, без сборки и фреймворков      |
| Структура страницы | Одна длинная страница `index.html`, навигация якорями          |
| CSS-архитектура    | Модульная: `tokens.css`, `base.css`, `components.css`, `sections.css` |
| Темы               | Светлая (по умолчанию по системе) + тёмная, ручной toggle       |
| Хранение темы      | `localStorage` (`artkull-theme`), анти-мерцание инлайн-скриптом |
| Шрифты             | Google Fonts по CDN: Inter, JetBrains Mono, `display=swap`      |
| Иконки             | Инлайн-SVG, стиль Lucide, без внешних библиотек                 |
| Форма              | Визуальная заглушка, без отправки данных                        |
| Логотип            | Векторный `assets/logo.svg` + `assets/favicon.svg`              |
| Поддержка браузеров| Последние 2 версии Chrome, Firefox, Safari, Edge               |

Ограничения: без бэкенда, без аналитики, без CMS, без сборщика, без CDN-библиотек
(кроме шрифтов).

## 3. Структура страницы

Порядок секций и их содержимое. Тексты ниже — черновые плейсхолдеры,
заменяются на реальные данные без изменения разметки.

### 3.1 Hero

Раскладка: 12 колонок, на десктопе две зоны — текст (7) и мини-дашборд (5).
Высота ~480px на десктопе.

Левая зона:
- Микро-лейбл: `● ДОСТУПЕН ДЛЯ ЗАКАЗА` (зелёная статус-точка + JetBrains Mono).
- H1: «Сайты под ключ. Быстро. Чисто. Без переплат.»
- Подзаголовок: «Разработка и запуск сайтов для бизнеса — от лендинга до каталога.
  Один человек, полная ответственность, никаких агентских наценок.»
- Кнопки: `Запустить проект` (primary, скролл к секции контактов),
  `Смотреть тарифы` (outline, скролл к секции услуг).

Правая зона — мини-дашборд (виджет, 4 метрики):

| Значение    | Лейбл     |
|-------------|-----------|
| 47          | проектов  |
| от 5 дней   | срок      |
| от 5 000 ₽  | бюджет    |
| 100%        | лично     |

Внизу виджета — статус-строка: `● Онлайн · отвечает быстро`.
Числа — JetBrains Mono 32px, анимируются стаггером при загрузке.

Фон карточки: лёгкое свечение акцентом в правом верхнем углу (subtle, не заливка).
В правом верхнем углу hero — кнопка переключения темы.

### 3.2 Услуги (тарифы)

Раскладка: 3 карточки по 4 колонки; на планшете/мобильном — стопка.

**Тариф 1 — «Сайт-визитка / Лендинг»**
- Бейдж `БАЗОВЫЙ` (neutral). Цена `от 5 000 ₽` · срок от 5 дней.
- Включено: персональный дизайн; HTML, CSS, JavaScript; SEO-оптимизация;
  бесплатный хостинг; адаптив под мобильные; форма обратной связи.
- Не входит: блог / CMS.
- Кнопка `Выбрать` (outline).

**Тариф 2 — «Сайт компании»** (выделенная: border акцента, усиленная тень,
приподнята, бейдж `ПОПУЛЯРНЫЙ` акцентной заливкой сверху по центру)
- Цена `от 15 000 ₽` · срок от 10 дней.
- Включено: всё из «Сайт-визитки»; многостраничная структура; CMS на выбор
  (Tilda / Astro / Craftum); каталог услуг; интеграция с CRM/почтой; анимации и
  интерактив; настройка Яндекс.Метрики.
- Кнопка `Выбрать` (primary).

**Тариф 3 — «Интернет-магазин / Каталог»**
- Бейдж `МАКСИМУМ` (neutral). Цена `от 35 000 ₽` · срок от 14 дней.
- Включено: всё из «Сайта компании»; каталог товаров с фильтрами; корзина и
  оформление заказа; платёжные системы; личный кабинет; интеграция со складом/1С.
- Не входит: мобильное приложение (отдельно).
- Кнопка `Обсудить` (outline).

Под карточками — плашка на всю ширину: «Нужно что-то нестандартное? Парсер,
Telegram-бот, интеграция с API — обсудим.» + ссылка `Связаться`.

### 3.3 О себе + преимущества

Bento: 1 большая карточка (6 колонок) + 3 малые.

**Профиль (6 колонок):**
- Аватар (квадрат, радиус 12) + `Имя Фамилия` + «Веб-разработчик · фриланс».
- Абзац: «Делаю сайты с 2019 года. Работаю один — от первого брифа до запуска.
  Это значит, что ты общаешься напрямую с человеком, который пишет код, а не с
  менеджером, который передаёт задачу дальше.»
- Теги: HTML, CSS, JavaScript, Astro, React, Tilda, SEO, Figma.
- Мини-статистика: `47` — проектов запущено; `5 лет` — в разработке.

**Плюс A — «Один человек, полная ответственность»** (иконка: пользователь):
«Никаких менеджеров и передачи между отделами. Ты говоришь с разработчиком
напрямую — от идеи до запуска. Это быстрее и дешевле.»

**Плюс B — «Цена без агентской наценки»** (иконка: тег/рубль):
«У агентства 30–50% счёта — это зарплаты и аренда. У меня нет офиса и отдела
продаж. Ты платишь за работу, а не за инфраструктуру.»

**Плюс C — «Скорость без потери качества»** (иконка: молния):
«Лендинг — за 5 дней. Сайт компании — за 10. Не потому что «тяп-ляп», а потому
что один человек не тратит время на согласования между тремя людьми.»

### 3.4 Этапы разработки

Карточка на всю ширину, заголовок «Как мы будем работать» + лейбл `ПРОЦЕСС`.
Timeline из 5 нод, соединённых линией. Под каждой нодой — декоративный
прогресс-бар с долей этапа.

| № | Этап               | Текст                                                                 | Доля |
|---|--------------------|-----------------------------------------------------------------------|------|
| 1 | Бриф               | Обсуждаем задачу, цели, сроки, бюджет. Заполняешь бриф или созваниваемся. Бесплатно. | 10% |
| 2 | Прототип и дизайн  | Структура страниц и визуал. Макеты в Figma. Правки до утверждения — без доплат. | 30% |
| 3 | Разработка         | Пишу код, верстаю, подключаю скрипты и интеграции. Прогресс виден на тестовом адресе. | 40% |
| 4 | Запуск             | Хостинг, домен, SSL, аналитика, SEO. Сайт в эфире.                    | 10% |
| 5 | Поддержка          | 30 дней бесплатной поддержки. Дальше — по договорённости, без абонплаты. | 10% |

На мобильных timeline разворачивается вертикально: ноды слева, текст справа.

### 3.5 CTA

Карточка 8 колонок по центру, контрастный фон (заливка акцентом).
- H2 (белый): «Запустим твой проект».
- Подзаголовок (белый 80%): «Напиши — и в течение дня получишь оценку стоимости
  и сроков. Без обязательств.»
- Форма в одну строку: `Имя`, `Телефон или email`, кнопка `Отправить заявку →`.
- Микро-текст: «Или напиши напрямую — Telegram · WhatsApp · Email».
- Декор: едва заметный точечный/сетчатый узор в правом верхнем углу.

Форма — заглушка: `preventDefault`, поля без реальной отправки, показывается
нейтральное сообщение «Заявка не отправляется — это демо».

Плейсхолдеры контактов: `@username`, `+7 000 000-00-00`, `you@example.com`,

## 4. Интерактив и поведение

- **Тема.** Инлайн-скрипт в `<head>` до рендера читает `localStorage` или
  `prefers-color-scheme` и ставит `data-theme` на `<html>`. Кнопка-toggle
  переключает и сохраняет выбор. Без мерцания (FOUC).
- **Анимации появления.** IntersectionObserver добавляет класс появления секциям
  один раз; при `prefers-reduced-motion: reduce` — отключено.
- **Стаггер метрик hero** и **анимация прогресс-баров** этапов.
- **Smooth-scroll** по якорям кнопок hero и ссылки `Связаться`.
- **Hover** карточек — подъём (см. дизайн-гайд).
- **Форма-заглушка** — перехват submit.

## 5. Доступность

См. раздел 10 дизайн-гайда. Обязательно: семантические лендмарки, `focus-visible`,
`aria-label` на иконках-ссылках и toggle, `aria-pressed` на toggle, контраст AA,
работа с клавиатуры, `prefers-reduced-motion`.

## 6. Производительность

- Шрифты с `display=swap` и `preconnect` к `fonts.gstatic.com`.
- Иконки — инлайн-SVG, без сетевых запросов.
- Без JS-библиотек; `app.js` — разумного размера, подключается с `defer`.
- Обязательно: `<meta name="viewport">`, `lang="ru"`, `<title>`, `meta description`.
- Open Graph-теги: `og:title`, `og:description`, `og:type`, `og:image`.
- Целевой Lighthouse Performance/Best Practices/Accessibility ≥ 90.

## 7. Файловая структура

```
index.html
css/
  tokens.css        # CSS-переменные, темы
  base.css          # reset, типографика, лендмарки
  components.css    # card, btn, badge, check, pill, metric, progress, field, toggle
  sections.css      # стили секций и bento-сетка
js/
  app.js            # тема, IntersectionObserver, стаггер, smooth-scroll, форма
assets/
  logo.svg
  favicon.svg
docs/
  design-guide.md
  spec.md
  plan.md
```

## 8. Вне scope

Реальная отправка формы и бэкенд; CMS/блог; мультиязычность; аналитика и счётчики;
портфолио/кейсы; сборщик и препроцессоры; полиграфический брендбук; SEO-страницы
под запросы.

## 9. Критерии приёмки

1. Сайт открывается как статика (`index.html` двойным кликом / на любом хостинге).
2. Все 6 секций и футер на месте, раскладка соответствует карте bento.
3. Светлая и тёмная темы; ручной переключатель работает, выбор сохраняется,
   стартовая тема — по системе; нет мерцания при загрузке.
4. Адаптив: 12/2/1 колонок на desktop/tablet/mobile, без горизонтального скролла.
5. Анимации появления и hover работают; при `prefers-reduced-motion` — отключены.
6. Форма не отправляет данные, показывает демо-сообщение.
7. Иконки — единый линейный набор, инлайн-SVG.
8. Контраст AA, клавиатурная доступность, `aria`-атрибуты на месте.
9. Валидная разметка; консоль без ошибок; Lighthouse ≥ 90 по ключевым метрикам.
