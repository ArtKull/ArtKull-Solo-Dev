# Спека: рефакторинг дизайна — стекло, градиент, свечение

- **Дата:** 2026-09-27
- **Статус:** утверждён дизайн, готово к планированию
- **Связанные документы:** `PRODUCT.md`, `DESIGN.md`, `reference.html`
- **Тема:** новый визуальный язык на основе `reference.html` с сохранением структуры лендинга

## 1. Цель

Привести оформление сайта к современному «технологичному» языку из
`reference.html`: градиентный акцент синий→фиолетовый, свечения (glow),
радиальные градиенты фона, селективное стекло, плавная смена темы. Сохранить
структуру лендинга, содержимое и рабочую форму.

Успех: посетитель видит цельный современный интерфейс в обеих темах; анимация
ощущается мягкой, но заметной; доступность (WCAG AA), производительность и
работа формы не деградируют.

## 2. Область

**Входит:**
- Полная переработка `css/*` (4 файла) под новую систему.
- Правки разметки `index.html` (шапка, классы стекла, `scroll-margin-top`).
- Новая липкая стеклянная шапка с якорной навигацией и мобильным меню.
- Расширение `js/app.js` (шапка, мобильное меню, активная ссылка, stagger).
- Переоформление `privacy.html` тем же словарём токенов.
- Переписывание `DESIGN.md` под новую систему.

**Не входит:**
- Любые изменения текстов, офферов, цифр, тарифов, сроков и порядка секций.
- `og-image` (SVG/PNG) — остаётся как есть.
- Изменение логики темы и формы (валидация, отправка, состояния).
- Новые секции, CMS, мультиязычность, аналитика.

## 3. Утверждённые решения

Диалог с заказчиком зафиксировал:

| Вопрос | Решение |
|---|---|
| Структурная метафора «окна приложения» | Визуальный язык + стеклянные панели; структура и якорная навигация сохраняются, без sidebar |
| Акцентная палитра | Полный градиент синий→фиолетовый |
| Моношрифт | Оставляем JetBrains Mono для чисел/лейблов |
| Уровень анимации | Умеренно-насыщенная (без параллакса и тяжёлых эффектов) |
| Тема по умолчанию | По системной (`prefers-color-scheme`), ручной выбор в `localStorage` |
| Границы рефакторинга | Переписать CSS полностью, обновить `DESIGN.md`, править HTML-разметку |
| `privacy.html` | Переоформить |
| Контент | Без изменений |
| Стратегия стекла | Селективное стекло (blur только на ключевых участках) |

## 4. Основы: цвет, глубина, радиусы

**Радиусы:** `--radius-window: 24px` (панели, hero-виджет, крупные окна),
`--radius-card: 16px`, `--radius-el: 10px` (кнопки, поля), `--radius-pill: 999px`.
Шкала отступов 4/8/12/16/24/32/48/64 и контейнер `1200px` сохраняются.

**Светлая тема:**
- Фон `#f0f4f8`; свечения фона `#bfdbfe` (синий) и `#e0e7ff` (индиго).
- Поверхности полупрозрачные (стекло), сплошная поверхность `#ffffff`.
- Текст `#0f172a`, приглушённый `#5b6b7f` (AA на фоне `#f0f4f8`).
- Градиент заливки `--grad-accent`
  `linear-gradient(135deg, #2563eb 0%, #7c3aed 100%)`; оба стопа дают
  ≥4.5:1 под белым текстом. Базовый акцент `#2563eb`, hover `#1d4ed8`.
- Фиолетовый оттенок — только фоновые свечения (`--bg-glow-2` `#e0e7ff` в
  светлой теме, `#4c1d95` в тёмной); под текстом фиолетовый не используется.
- Статусы: success `#059669`, warning `#d97706`, danger `#dc2626`, info `#0891b2`.
- Границы `#e2e8f0`, hover/strong `#cbd5e1`.
- Стекло: `rgba(255,255,255,.72)` + `blur(20px)` + граница `rgba(255,255,255,.6)`
  + внутренний верхний highlight.

**Тёмная тема:**
- Фон `#0a0e27` (глубокий navy); свечения `#1e3a8a` и `#4c1d95`.
- Поверхности `#1e293b`, сплошная `#0f172a`.
- Текст `#f8fafc`, приглушённый `#94a3b8`.
- Градиент заливки — тот же `--grad-accent` (`#2563eb → #7c3aed`), AA-safe под
  белым текстом; светло-синий `#3b82f6` — акцент границ/иконок/прогресса;
  hover-текст акцента — `#60a5fa`.
- Статусы: success `#10b981`, warning `#f59e0b`, danger `#ef4444`, info `#06b6d4`.
- Границы `rgba(255,255,255,.08)`, hover `rgba(255,255,255,.15)`.
- Стекло: `rgba(30,41,59,.6)` + `blur(20px)` + граница `rgba(255,255,255,.08)`
  + верхняя внутренняя световая линия.

**Глубина.**
- Светлая: тень покоя `0 4px 20px rgba(0,0,0,.06)`; `--shadow-lifted`
  `0 8px 30px rgba(0,0,0,.1)`; `--shadow-window` `0 25px 60px rgba(0,0,0,.12)`;
  `--glow-primary` `0 4px 15px rgba(37,99,235,.2)`.
- Тёмная: слабая тень `0 4px 20px rgba(0,0,0,.3)` + `--glow-primary`
  `0 0 20px rgba(59,130,246,.3)`. Свечение — основной акцент вместо тени.
- Фон страницы — фиксированный декоративный слой с радиальными градиентами
  (позиции ~20%/30% и ~80%/70%, как в reference).

**Named Rules (новые, входят в `DESIGN.md`):**
- **Gradient-Is-Fill.** Градиент применяется только как заливка или декор
  (кнопки, бейджи, прогресс, glow). Текст градиентом не набирается.
- **Solid-Text-On-Glass.** Текст на стеклянной поверхности всегда сплошным
  цветовым токеном, не полупрозрачным.
- **One-Glow.** Свечение — акцент, а не украшение: не более двух светящихся
  элементов в зоне видимости.

Сохраняется прежнее правило: белый текст допустим только на заливке
`--grad-accent` и `--accent-solid`, у которых оба стопа дают контраст ≥4.5:1
под белым текстом. Светло-синий `#3b82f6` и фиолетовый оттенок под текстом
не используются.

## 5. Типографика и вёрстка

**Типографика** (роли и шрифты сохраняются):
- Display H1 56px/1.2/−0.02em → 34px на мобильном.
- Headline H2 32px → 26px на мобильном.
- Title 20/600; Body 16/1.6; Small 14.
- Label mono 12px uppercase 0.08em; Metric mono 32px, цена 24px.
- Inter — весь читаемый текст; JetBrains Mono — числа, цены, статусы, лейблы.
- Градиентный текст не используется (см. Gradient-Is-Fill); акцент в заголовке —
  сплошной синий/фиолет.

**Сетка:** 12-колоночный bento, `gap 16px`, контейнер `1200px`, паддинг 24px.
Размеры блоков сохраняются: hero 7/5, тарифы 4/4/4, профиль 6 + фичи 3/3/6.
Вертикальный ритм секций 64px (десктоп) / 40px (мобильный).
Брейкпоинты: ≥1024px (12 колонок), 640–1023px (2 колонки), <640px (1 колонка).

**Липкая стеклянная шапка (новое):**
- Высота ~64px, стекло (blur), логотип + якорные ссылки
  *Услуги · Почему я · Процесс · Связаться* + переключатель темы.
- При скролле — состояние `.is-scrolled`: усиленный blur, нижняя граница,
  повышенная плотность фона.
- Активная секция подсвечивается акцентом в навигации.
- Мобильный: кнопка-бургер, раскрывающая стеклянную панель меню.
- Переключатель темы переезжает из угла hero в шапку.

**Детали:** у секций добавляется `scroll-margin-top`, равный высоте шапки, чтобы
якоря не прятались под ней. Идентификаторы секций (`#services`, `#about`,
`#process`, `#cta`, `#contacts`) сохраняются.

## 6. Компоненты

**Кнопки.**
- Primary: градиентная заливка + `--glow-primary`, белый текст; hover —
  `brightness(1.08)`, `translateY(-1px)`, усиление свечения; `:active` —
  `translateY(0)`.
- Outline/secondary: стеклянная поверхность с границей; hover — акцентная
  граница и лёгкое свечение.
- Ghost: только текст акцентом.
- Высоты: 44px, в CTA — 48px. `focus-visible` — кольцо `2px` акцента, offset 2px.

**Карточки.** Лёгкое стекло: полупрозрачный фон + 1px граница + внутренний
верхний highlight (`inset 0 1px 0 rgba(255,255,255,.06)`) + тень покоя. Hover —
подъём `-4px`, `--shadow-lifted`, граница с акцентным оттенком; в тёмной теме —
мягкий glow. `card--accent` (популярный тариф) — градиентная граница, подъём
8px, усиленное свечение, бейдж «Популярный» с градиентной заливкой.
`card--flat` — без эффектов.

**Hero-виджет** — настоящее стекло (blur) + радиальное акцентное свечение в углу
+ статус-строка с зелёной точкой. Один из двух «настоящих стеклянных» объектов
(второй — шапка) в дополнение к акцентным панелям.

**Бейджи и статусы.** Neutral — полупрозрачная поверхность; accent — градиентная
заливка, белый текст. Статус-точки: зелёная с ореолом / серая. Расширенная
палитра статусов (success/warning/info/danger) зарезервирована; новые смыслы в
текстах не выдумываются.

**Прогресс-бары** — трек полупрозрачный, заливка градиентная, анимация `scaleX`
сохраняется.

**Timeline** — узлы 36px с mono-номерами, соединительная линия с градиентным
затуханием, акцентное кольцо у активного этапа.

**Поля ввода** — полупрозрачная поверхность; focus — кольцо
`0 0 0 3px` из `accent-glow`; ошибка — красная граница + ореол. Логика
валидации, live-статусы, счётчик заполнения и состояния кнопки сохраняются.

**CTA-панель** — единственная крупная градиентная заливка страницы
(синий→фиолет) + свечение, белый текст, стеклянные поля внутри.

**Контакты** — MAX остаётся единственным primary-действием (градиентная
подложка/граница); Telegram/email/телефон — приглушённые ссылки; соцсети —
иконки 44px. **Футер** — стеклянная полоса с верхней границей.

**Доступность компонентов:** `focus-visible` на всех интерактивных элементах,
контраст текста ≥4.5:1, `aria` на иконочных ссылках и переключателе,
`prefers-reduced-motion`.

## 7. Движение

- Смена темы: `transition` фона/текста/границ 0.3s.
- Фоновые свечения: медленное «дыхание» ~16s (лёгкий сдвиг и прозрачность) на
  отдельном фиксированном слое.
- Появление секций: staggered, инкрементальная задержка ~60ms, `translateY(16px)`
  + opacity, 500–600ms.
- Hover-подъём карточек/кнопок, `scaleX`-прогресс, состояния формы — как сейчас.
- Шапка: уплотнение blur при скролле, подсветка активной ссылки.
- Очень сдержанный микро-пульс зелёной статус-точки.
- `prefers-reduced-motion: reduce` отключает свечения, stagger и пульс, reveal
  становится мгновенным.

## 8. Архитектура реализации

Оставляем текущее разбиение CSS на 4 файла:
- `css/tokens.css` — темы, градиенты, glow, glass, статусы, радиусы (существенно
  растёт).
- `css/base.css` — reset, фон-свечения, типографика, focus.
- `css/components.css` — кнопки, карточки, стекло, бейджи, поля, шапка,
  мобильное меню.
- `css/sections.css` — hero, услуги, about, процесс, CTA, контакты, футер.
- `index.html` — новая разметка шапки, `scroll-margin-top`, классы стекла.
  Идентификаторы и разметка формы сохраняются (от них зависит JS).
- `js/app.js` — добавляются состояние шапки, мобильное меню, активная ссылка,
  индекс stagger; логика темы и формы не меняется. Инлайн anti-FOUC скрипт
  остаётся.
- `DESIGN.md` — переписывается под новую систему.
- `privacy.html` — переоформляется тем же словарём токенов.

## 9. Производительность и надёжность

- Вместо `background-attachment: fixed` — фиксированный декоративный слой со
  свечениями (дешевле при скролле на мобильных).
- `backdrop-filter: blur()` только на шапке, hero-виджете и акцентных панелях.
- Fallback через `@supports not (backdrop-filter: blur())` — непрозрачная
  поверхность.
- Контраст текста держится на сплошных или достаточно плотных подложках.
- `will-change` применяется точечно.

## 10. Верификация

Автотестов на вёрстку нет. Ручная проверка:
- Обе темы (светлая/тёмная), старт по системной, отсутствие мерцания.
- Три брейкпоинта (≥1024 / 640–1023 / <640) + мобильное меню.
- Клавиатурная навигация и `focus-visible` по всей странице.
- `prefers-reduced-motion` — свечения/stagger/пульс отключены.
- Без JS — контент читается, reveal-контент не скрыт.
- Отправка формы работает (успех, ошибки валидации, fallback).
- `privacy.html` — обе темы, читаемость, ссылка из футера.

## 11. Риски

- Пёстрый фон под стеклом может усложнить контраст → митигация: стекло только на
  ключевых участках, текст на плотных подложках, `--shadow`/границы для разделения.
- Blur дорогой на слабых устройствах → митигация: ограниченный набор стеклянных
  элементов, fallback без `backdrop-filter`.
- Градиент и фиолетовый могут «удешевить» вид → митигация: правило One-Glow и
  сохранение сдержанности (градиент только в заливках, не в тексте).
