# Спека: явное согласие на Яндекс.Метрику (cookie-баннер)

- **Дата:** 2026-09-28
- **Статус:** утверждён дизайн, готово к планированию
- **Связанные документы:** `privacy.html`, `DESIGN.md`

## 1. Цель

Привести сбор аналитики в соответствие с 152-ФЗ: Яндекс.Метрика не должна
загружаться и устанавливать cookie до явного согласия посетителя. Согласие должно
быть конкретным, информированным и отзываемым.

Успех: до клика «Да, согласен» браузер не обращается к `mc.yandex.ru`; после
клика — счётчик работает как раньше; выбор запоминается; его можно изменить или
отозвать из подвала сайта; отказ полностью отключает аналитику.

## 2. Область

**Входит:**
- Удаление инлайн-счётчика и `<noscript>`-пикселя из `index.html`.
- Новый модуль `js/consent.js`: хранение решения, показ баннера, отложенная
  загрузка Метрики, отзыв согласия.
- Разметка баннера в `index.html`, стили — в `css/components.css`.
- Кнопка «Настройки cookie» в подвале `index.html`.
- Абзац о согласии на cookie в `privacy.html`.
- Отключение `webvisor` в конфигурации счётчика.
- Актуализация `PRODUCT.md`: снять «аналитика и счётчики» из «Вне scope».
- **Отдельная задача:** самохостинг шрифтов (убрать обращения к Google Fonts)
  — см. раздел 13.

**Не входит:**
- Гранулярность по категориям (только «Да» / «Нет»).
- Прочие вопросы передачи данных за рубеж (кроме шрифтов).
- Пересборка текста политики и юридическая экспертиза формулировок.
- Аналитика на других страницах (сейчас Метрика только в `index.html`).

## 3. Модель согласия и хранение

Единственный ключ: `localStorage['artkull-consent']` со значением JSON:

```json
{ "v": 1, "value": "granted", "ts": "2026-09-28T12:00:00.000Z" }
```

- `v` — версия схемы (позволяет инвалидировать старые записи при смене правил).
- `value` — `"granted"` или `"denied"`.
- `ts` — момент решения (ISO 8601, UTC), доказательство согласия.

Логика при загрузке страницы:

| Состояние хранилища | Баннер | Метрика |
|---|---|---|
| Нет записи | показывается | не загружается |
| `granted` | скрыт | загружается сразу |
| `denied` | скрыт | не загружается |
| `localStorage` недоступен | показывается каждый визит | не загружается до клика; «Да» включает только на текущую сессию (in-memory) |

Запись в `localStorage` завёрнута в `try/catch`. Безопасный дефолт — отсутствие
аналитики, пока согласие не получено.

## 4. Баннер: разметка

В конце `<body>` в `index.html`, перед `js/consent.js`:

```html
<div
  class="cookie-banner"
  id="cookie-banner"
  role="region"
  aria-label="Уведомление об использовании cookie"
  hidden
>
  <p class="cookie-banner__text">
    Используем файлы cookie для работы сайта, а Яндекс.Метрику — для улучшения
    сервиса. Вы согласны на сбор аналитических данных? Ознакомьтесь с
    <a href="privacy.html" target="_blank" rel="noopener"
      >Политикой конфиденциальности</a
    >.
  </p>
  <div class="cookie-banner__actions">
    <button type="button" class="btn btn--primary" data-consent="granted">
      Да, согласен
    </button>
    <button type="button" class="btn btn--ghost" data-consent="denied">
      Нет, спасибо
    </button>
  </div>
</div>
```

- `hidden` — без JS баннер не виден (и Метрика тоже не грузится, так как
  `<noscript>`-пиксель удалён). JS снимает атрибут.
- Баннер немодальный: страница читается и скроллится, фокус не запирается.
- Кнопки — `btn`/`btn--primary`/`btn--ghost` из существующего набора.

## 5. Баннер: стили

В `css/components.css`, на существующих токенах:

- Фиксирован снизу (`position: fixed; inset-inline: 0; bottom: 0`), визуально как
  `card`/панель сайта; контейнер-обёртка для отступов по сетке.
- Текст и кнопки в одну строку на десктопе, в столбик на мобиле
  (`flex-wrap`/media-запрос).
- Компактная анимация появления (`opacity`/`translateY`) с учётом
  `prefers-reduced-motion: reduce` — при reduce показывается мгновенно.
- Без конфликта с футером и мобильным меню (проверить `z-index`).

## 6. Загрузка Метрики (`js/consent.js`)

- Файл подключается в `index.html` через `<script src="js/consent.js" defer>`.
- Внутри — IIFE, как `js/app.js`. Никаких зависимостей.
- `loadMetrika()`:
  - guard `window.__artkullMetrikaLoaded`, чтобы не грузить дважды;
  - создаёт `<script async src="https://mc.yandex.ru/metrika/tag.js?id=113122431">`
    и вставляет в `<head>` только в момент вызова;
  - вызывает `ym(113122431, 'init', { ... })`.
- Опции init (без `webvisor`):

```js
ym(113122431, 'init', {
  ssr: true,
  clickmap: true,
  ecommerce: 'dataLayer',
  referrer: document.referrer,
  url: location.href,
  accurateTrackBounce: true,
  trackLinks: true,
});
```

- Номер счётчика `113122431` и URL `tag.js` — те же, что сейчас; вынести в
  константы файла.
- Инлайн-счётчик и `<noscript>`-блок полностью удаляются из `index.html`.

## 7. Изменение и отзыв согласия

Кнопка в подвале `index.html`:

```html
<button type="button" class="footer__link" data-consent-settings>
  Настройки cookie
</button>
```

`.footer__link` — новый класс: сбросить вид кнопки (прозрачный фон, наследуемый
шрифт и цвет, `cursor: pointer`) и повторить оформление `.footer a`
(`text-decoration: underline; text-underline-offset: 3px`, hover —
`var(--accent-text)`).

Поведение по клику:

- Текущее `denied` или отсутствие записи → снова показываем баннер, ничего не грузим.
- Текущее `granted` → снова показываем баннер (пользователь может переключить).

Смена решения:

- `denied → granted`: сохраняем `granted` + `ts`, скрываем баннер, вызываем
  `loadMetrika()` сразу (без перезагрузки).
- `granted → denied`: сохраняем `denied` + `ts`, удаляем cookie Метрики,
  перезагружаем страницу (`location.reload()`). После перезагрузки счётчик не
  поднимается.

Удаление cookie Метрики: перебрать `document.cookie.split(';')` и удалить все
имена с префиксом `_ym` и известный набор (`ymex`, `yandexuid`, `yuidss`, `i`),
выставляя `Max-Age=0` для `path=/` и для текущего host (без `domain`, host-only).

## 8. Доступность

- `role="region"` + `aria-label` у баннера; текст читается скринридером.
- Кнопки — нативные `<button type="button">`, доступны с клавиатуры.
- `aria-live` не используется (уведомление не срочное, не модальное).
- Контраст текста и кнопок — не ниже AA (использовать существующие токены).
- Кнопка «Настройки cookie» доступна с клавиатуры и озвучивается как кнопка.

## 10. Тестирование

Автотестов для клиентского JS в проекте нет (`tests/` — PHP для формы).
Проверка ручная, по чек-листу:

1. **Чистый storage** (DevTools → Application → Clear): при загрузке баннер виден;
   в Network нет ни одного запроса к `mc.yandex.ru`.
2. **«Да, согласен»**: баннер скрывается; в Network появляется запрос
   `tag.js?id=113122431`; в `localStorage` запись `granted` с `ts`.
3. **Reload после «Да»**: баннер не показывается; счётчик грузится сразу;
   вхождений в Метрике видно (проверить в кабинете/через `ym`).
4. **«Нет, спасибо»**: баннер скрывается; запросов к `mc.yandex.ru` нет; запись
   `denied`.
5. **Reload после «Нет»**: баннер не показывается, запросов нет.
6. **«Настройки cookie»**: баннер открывается заново; переключение на «Да»
   включает счётчик; переключение на «Нет» удаляет cookie `_ym*` и перезагружает
   страницу, после чего запросов нет.
7. **Приватный режим/заблокированный `localStorage`**: баннер виден, Метрика не
   грузится до клика; после «Да» работает в рамках сессии без ошибок в консоли.
8. **Доступность**: баннер и кнопки доступны с клавиатуры; скринридер читает
   `aria-label` и текст; при `prefers-reduced-motion` анимации нет.
9. **Регресс**: форма заявки, тема и мобильное меню работают как раньше.

## 12. Отдельная задача: самохостинг шрифтов

**Проблема.** Обе страницы (`index.html`, `privacy.html`) подключают
`fonts.googleapis.com` и `fonts.gstatic.com`. Каждый запрос передаёт в Google
IP-адрес и User-Agent посетителя — это иностранный сервис и противоречит
формулировке п.4 политики «Зарубежные сервисы не используются».

**Решение.** Самохостинг тех же шрифтов, без внешних обращений.

- Скачать файлы `woff2` с нужными подмножествами (**латиница + кириллица**):
  Inter `400/500/600/700`, JetBrains Mono `500`. Положить в `assets/fonts/`.
- Добавить новый `css/fonts.css` с `@font-face` (`font-family`, `font-weight`,
  `font-style: normal`, `src: url(...) format('woff2')`, `font-display: swap`,
  по возможности `unicode-range` для латиницы и кириллицы).
- Подключить `css/fonts.css` в обеих страницах **до** `css/tokens.css`.
- Удалить из обеих страниц оба `<link rel="preconnect">` (googleapis/gstatic) и
  `<link href="https://fonts.googleapis.com/css2?...">`.
- Семейства в `css/tokens.css` (`--font-sans`, `--font-mono`) не меняются.
- Лицензии Inter и JetBrains Mono — SIL OFL 1.1; положить текст лицензии в
  `assets/fonts/OFL.txt` (требование лицензии при распространении).
- `PRODUCT.md`: строку «Без CDN-библиотек, кроме Google Fonts» заменить на
  «Без CDN-библиотек и внешних шрифтов».

**Проверка (ручная):**
1. В Network нет ни одного запроса к `fonts.googleapis.com` и `fonts.gstatic.com`.
2. Шрифты отдаются с домена сайта (`200`, `woff2`).
3. Внешний вид текста и заголовков не изменился (Inter / JetBrains Mono,
   включая кириллицу и моноширинные акценты).
4. Нет длительного невидимого текста (`font-display: swap`), при
   `prefers-reduced-motion` поведение не зависит от шрифтов.

**Файлы задачи:**
| Файл | Изменение |
|---|---|
| `assets/fonts/*.woff2` | новые файлы шрифтов (латиница + кириллица) |
| `assets/fonts/OFL.txt` | текст лицензии SIL OFL 1.1 |
| `css/fonts.css` | новый файл с `@font-face` |
| `index.html` | убрать preconnect и Google Fonts; подключить `css/fonts.css` |
| `privacy.html` | то же |
| `PRODUCT.md` | убрать исключение «кроме Google Fonts» |

## 13. Риски и ограничения

- **Отзыв без перезагрузки.** До перезагрузки уже загруженный счётчик может
  продолжать слать события; для чистого отзыва выполняется `location.reload()`
  после удаления cookie. Это осознанный компромисс.
- **Cookie Метрики.** Список имён (`_ym_uid`, `_ym_d`, `_ym_isad`,
  `_ym_visorc`, `ymex`, `yandexuid`, `yuidss`, `i`) может меняться со стороны
  Яндекса; реализовать удаление по префиксу `_ym` + фиксированный список.
- **Первый визит без JS.** Сбор не происходит (`noscript` удалён), но и
  аналитика не пишется — цена соответствия требованиям.
- **`webvisor` отключается.** Записи сессий и их отладка больше недоступны;
  это сделано осознанно из-за риска записи значений формы (имя, телефон).
- **Шрифты.** Самохостинг (раздел 12) устраняет обращение к Google Fonts;
  до его выполнения внешний запрос остаётся. Нужно следить за актуальностью
  файлов и лицензии OFL.
