# SEO & GEO-аудит сайта https://artkull.ru/

> **Дата аудита:** 28.09.2026
> **Область:** главная страница, страница политики конфиденциальности, HTTP-заголовки и коды ответа.
> **Методология и ограничения.** Данные собраны прямым анализом HTML/CSS/JS, HTTP-заголовков и кодов ответа сервера (curl), плюс проверкой индексации в Bing. Встроенный веб-поиск был недоступен (ошибка провайдера), поэтому факторы, требующие Google Search Console / Яндекс.Вебмастера / PageSpeed Insights, помечены как **«Требует ручной проверки»** с инструкцией.

**Важный контекст:** сайт — **одностраничник (SPA-подобный лендинг)** на статике, размещённый на **GitHub Pages** (ответ сервера `Server: GitHub.com`, CDN Fastly). Все разделы живут по якорям `#services`, `#about`, `#process`, `#contacts` — отдельных URL у услуг/о нас/контактов **нет**. Это фундаментально ограничивает SEO.

## 1. Краткое резюме (Executive Summary)

**Общая оценка: 5 / 10.**
Сайт технически качественный как лендинг: чистый семантичный HTML, self-hosted шрифты woff2, сжатие gzip (30 823 → 7 316 байт), 1 корректный H1, адаптивная вёрстка, осмысленные Title/Description. Но **базовой SEO-инфраструктуры нет вообще**: отсутствуют robots.txt, sitemap.xml, canonical, любая микроразметка Schema.org, отдельные посадочные страницы. В Bing сайт **не индексируется** (0 результатов). Для коммерческого продвижения по всей России этого недостаточно.

**Топ-3 критических проблемы (Quick Wins):**
1. **Нет `robots.txt` и `sitemap.xml`** — оба отдают 404. Поисковики не получают директив по сканированию и карту сайта.
2. **Полностью отсутствует микроразметка Schema.org** (`ld+json` = 0 совпадений). Google/Яндекс и ИИ-поисковики не понимают, что это за организация, чем занимается и по каким ценам.
3. **OG-изображение битое**: `og:image="assets/og-image.png"` — и относительный путь (нельзя для OG), и файл отдаёт **404**. Соцсети и AI-краулеры получают превью без картинки.

**Топ-3 возможности для роста трафика:**
1. **Создание отдельных посадочных страниц** под услуги и города («создание сайтов в Тюмени», «разработка интернет-магазина», «заказать лендинг») — сейчас весь коммерческий спрос упирается в один URL.
2. **Блог / база знаний** под информационные запросы + усиление E-E-A-T и попадание в ответы ИИ (AEO).
3. **Яндекс.Бизнес + Google Business Profile + портфолио кейсов и отзывы** — доверие и локальная выдача.

## 2. Техническое SEO (Technical SEO)

### Индексация и сканирование

| Фактор | Значение | Статус |
|---|---|---|
| `robots.txt` | `https://artkull.ru/robots.txt` → **404** | ❌ отсутствует |
| `sitemap.xml` | `https://artkull.ru/sitemap.xml` → **404** | ❌ отсутствует |
| `meta name="robots"` | отсутствует (по умолчанию index) | ⚠️ желательно явно |
| `rel="canonical"` | **отсутствует** (0 совпадений) | ❌ критично при дублях |
| `/index.html` vs `/` | **оба 200** | ⚠️ дубль без canonical |
| `/privacy.html` vs `/privacy` | **оба 200** и содержат одинаковый контент | ❌ дубль без canonical |
| `404.html` | отсутствует → отдаётся дефолтная страница GitHub | ⚠️ |
| `llms.txt` / `llms-full.txt` | **404** | ⚠️ упущенная GEO-возможность |

**Дубли подтверждены замером:** `curl -I /index.html` и `curl -I /` — оба 200; `privacy` и `privacy.html` — оба 200. Без canonical это размывает сигналы. В политике конфиденциальности указан адрес `https://artkull.ru/privacy`, а в меню формы — `privacy.html` — **несогласованность ссылок**.

**Исправить:** добавить `robots.txt` и `sitemap.xml`, прописать `<link rel="canonical" href="https://artkull.ru/" />` для главной и `.../privacy.html` для политики, унифицировать ссылки на политику.

### Core Web Vitals

Наблюдаемые параметры: HTML 30.8 КБ (gzip 7.3 КБ), суммарный CSS ~30.4 КБ в **4 отдельных render-blocking файлах** (`fonts/tokens/base/components/sections.css`), JS 21.6 КБ (`app.js` + `consent.js`, оба `defer`), 4 шрифта woff2 общим весом **~84 КБ** (крупнейший `inter-latin.woff2` — 48 КБ). Контентных изображений на странице нет (1 SVG-логотип), т.е. тяжёлого LCP-элемента нет.

- **LCP** — предположительно в норме (текстовый hero, `<h1>`), но 4 блокирующих CSS + отсутствие `preload` шрифтов задерживают отрисовку. → *Требует ручной проверки в PageSpeed Insights (pagespeed.web.dev).*
- **CLS** — риск небольшой: тема применяется inline-скриптом в `<head>` (FOUC исключён), но подключение Inter через `font-display: swap` без `size-adjust` может давать сдвиг. → рекомендуется `font-display: optional` или preload + fallback метрики.
- **INP** — риска не видно (JS лёгкий, defer). → *Требует ручной проверки в GSC → Core Web Vitals.*

**Улучшения:** инлайнить critical CSS, добавить `<link rel="preload" as="font" ... crossorigin>` для `inter-cyrillic.woff2` и `inter-latin.woff2` (основной трафик — РФ, латиница меньше нужна — можно `preload` только cyrillic).

### Мобильная адаптивность и безопасность

- `viewport` присутствует, вёрстка адаптивная (bento/col-классы, отдельные mobile-стили) — ✅.
- HTTPS работает, `http://` → `https://` отдаёт **301** — ✅.
- **HSTS, CSP, X-Content-Type-Options, Referrer-Policy — отсутствуют** (проверено в заголовках). GitHub Pages часть заголовков задать не даёт — компенсировать на уровне Cloudflare-прокси, если важен security-аудит.
- Смешанного контента не обнаружено — ✅.

### Микроразметка Schema.org

**Отсутствует полностью.** Для ниши «web-разработка» необходимо добавить типы:

- `Organization` / `ProfessionalService` (или `LocalBusiness`) — с `name`, `logo`, `url`, `telephone`, `email`, `areaServed: RU`, `address` (Тюмень).
- `Person` — автор Артём Кульчинский (`jobTitle`, `knowsAbout`, `sameAs`: GitHub, VK, Telegram).
- `Service` + `Offer` / `AggregateOffer` — для трёх тарифов с ценами «от 5 000 / 15 000 / 35 000 ₽».
- `FAQPage` — для блока вопросов (которого сейчас нет).
- `WebSite` + `BreadcrumbList` — при появлении внутренних страниц.

### Структура URL и ЧПУ

- Всё на одном URL с якорями (`#services`, `#about`, `#process`, `#contacts`). Якорные секции **не индексируются как отдельные документы** — нельзя занять позиции по «заказать лендинг», «разработка интернет-магазина» и т.п. по отдельности.
- Требуется ЧПУ-структура вида `/uslugi/sozdanie-saitov/`, `/uslugi/internet-magazin/`, `/portfolio/`, `/blog/`.

## 3. Внутренняя и контентная SEO-оптимизация (On-Page SEO)

- **Страница privacy.html** имеет Title, но **нет `meta description`** и `meta robots` — для непубличной страницы допустимо, но лучше `noindex`.

### Заголовки H1–H6

Проверено: **H1 — 1 шт.** (`Сайты под ключ...`), **H2 — 5 шт.** (Услуги, Почему я, Как мы будем работать, Запустим ваш проект, Связаться), **H3 — 14 шт.** Иерархия корректная, множественных H1 нет. ✅ Это сильная сторона.

### Контент и E-E-A-T

- **Автор указан:** Артём Кульчинский, роль «Веб-разработчик · фриланс», стек (HTML/CSS/JS/Python/React/FastAPI/SEO/Figma), ссылка на GitHub. Это плюс для экспертности.
- **Пробелы:** нет портфолио/кейсов с цифрами, нет отзывов, не указан опыт (лет), нет ИНН/ОГРНИП, юридические данные спрятаны только в политике конфиденциальности (ФИО + адрес квартиры). Для E-E-A-T и доверия ИИ это критично — добавить блок «О себе» с фактами, стажем, стеком и ссылками на реальные проекты.
- Контента мало для ниши: нет статей, гайдов, объяснений процесса на уровне пользы.

### Внутренняя перелинковка

## 4. GEO-оптимизация: Generative Engine Optimization (под ИИ-поиск)

**Как сайт выглядит для ChatGPT / Perplexity / Яндекс Нейропоиска:** практически невидимо. ИИ-системы строят ответы из структурированных сущностей и фактов. Сейчас на сайте **нет ни одного `ld+json`**, нет `llms.txt`, нет FAQ, нет чётко вычлененной сущности «компания/специалист».

- **Упоминаемость и однозначность бренда:** бренд «ArtKull» есть в Title/H1/логотипе, но **Knowledge Graph не формируется** — нет `Organization`-разметки, нет `sameAs`-ссылок на соцпрофили в разметке. Bing по `artkull.ru` — **0 результатов** (проверено), сайт вне индекса этого движка (а на нём частично основаны ChatGPT/Bing Copilot).
- **Фактологичность (AEO):** сильная база — есть тарифы, сроки, состав услуг, процесс из 5 шагов. Это отлично парсится, но **не размечено** и не сгруппировано в переиспользуемые ответы. Стоит вынести в таблицу «услуга → цена → срок → что входит» + FAQ.
- **Страница «О нас» и контакты:** отдельного URL «О нас» нет; юрданные (ФИО, адрес, e-mail, телефон) только в политике конфиденциальности. **Нет ИНН/ОГРНИП** — для ИИ и Google это снижает доверие. Контакты (MAX, Telegram, e-mail, телефон) есть в разделе `#contacts`.
- **FAQ:** раздела FAQ **нет вообще**. Это ключевой инструмент AEO — добавьте 6–10 вопросов («Сколько стоит сайт?», «Сроки создания сайта?», «Работаете ли по всей России?», «Что входит в поддержку?») с разметкой `FAQPage`.
- **`llms.txt`:** отсутствует. Добавление `https://artkull.ru/llms.txt` с описанием компании/услуг — набирающая практика для GEO.
